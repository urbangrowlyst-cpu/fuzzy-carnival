# Patasa review demo (integrated)

This Next.js site now includes the Patasa review generator at `/review`.

## What was added

| Path | Purpose |
| --- | --- |
| `public/review/` | The review page (HTML, CSS, JS, config, assets) |
| `app/review/page.tsx` | Redirects `/review` to the static review page |
| `app/api/review/route.js` | Next.js API route that runs the hardened review handler |
| `server/review-handler.js` | Rate limiting, validation, AI call, backup reviews |
| `lib/config-check.js`, `lib/review-fallback.js` | Shared config validation and backup drafts |
| `shop-config.js` | Server-side shop config used by the API |
| `public/review/shop-config.js` | Browser copy of the shop config |
| `next.config.mjs` | Bundles the handler files and sets CSP/security headers for `/review/*` |
| `netlify.toml` | Same security headers for Netlify deployments |
| `.env.example` | Environment variable template |

## Run locally

Node.js **22.9 or newer** is required (Tailwind 4). Then:

```bash
npm install
copy .env.example .env.local
# edit .env.local and set AI_API_KEY
npm run dev
```

Open:

- `http://localhost:3000/review` â€” the review demo
- `http://localhost:3000/ai-review-tool` â€” marketing page with the "Open live demo" button

## Deploy

Set these in the hosting dashboard (never commit them):

- `AI_API_KEY` â€” Google AI Studio key (required for live drafts)
- `AI_MODEL` â€” optional, defaults to `gemini-3.5-flash-lite`
- `ALLOWED_ORIGIN` â€” your site origin, e.g. `https://urbangrowlyst.in` (only needed if the page and API are on different origins)
- `RATE_LIMIT_SALT` â€” any private random phrase

The key is read only in `server/review-handler.js` and sent to Google from the
server. It is never included in browser code.

## Editing the shop

Edit **both** config copies with the same values:

- `shop-config.js` (API)
- `public/review/shop-config.js` (browser)

`settings.googleReviewLink` is set to `https://urbangrowlyst.in`. The copy
button copies the draft and then opens that link. Replace it with a different
link if needed. The page disables itself and shows a setup notice while the
link is a placeholder.

The review page has no Instagram or Facebook links; the footer goes straight to
the tagline, address and copyright.

### How the AI drafts are written

Each draft is generated by Gemini from the shop name, `Nerul`, the selected
dish, one phrase from `seoKeywords`, and at most one entry from `shopFacts`.
The prompt asks for 2 to 3 natural first-person sentences that read like a
local recommendation, with the SEO phrase used once in the first or second
sentence. The server rejects drafts that invent prices, offers, awards, staff,
history, health claims or extra dishes, and falls back to a safe backup draft.

`AI_MODEL` defaults to `gemini-3.5-flash-lite`. The handler retries once on a
transient 503/429 and asks the model again if a draft fails validation.

## Security notes

- `/review/*` sends a strict CSP, `X-Frame-Options: DENY`, `nosniff`, and a
  referrer policy.
- The API validates the body, caps size/depth, rate limits per IP, filters
  output, and falls back to a safe backup draft.
- The in-memory rate limit is per server instance. For hard protection, add a
  shared store (Upstash/Redis) or a platform WAF rule, and set a Gemini quota
  plus a billing alert.
- The original `.env.example` in this project contained a real Telegram bot
  token. It has been replaced with placeholders in this copy. **Rotate that
  token with BotFather** if the project has been shared or committed anywhere.
